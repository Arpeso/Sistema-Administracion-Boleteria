# Sistema-Administracion-Boleteria
Sistema de Administración de Boletería | C# (.NET Framework) & MySQL

Repositorio: https://github.com/Arpeso/Sistema-Administracion-Boleteria

    Aplicación de escritorio desarrollada bajo Arquitectura en 3 Capas (Presentación, Negocio, Datos) para la gestión y venta interactiva de boletos.

    Implementación de operaciones CRUD completas con persistencia de datos en MySQL y manejo estructurado de entidades.

    Diseño de interfaz de usuario enfocado en la validación de datos de entrada y control de flujos de eventos.
